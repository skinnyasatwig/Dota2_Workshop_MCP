## What “minimal Hammer interaction” means

Most layout iteration can now happen in JSON plus generated previews. Simple flat or sloped convex/concave world solids, rectangular/profile arches, checked bridge decks/approaches, regular rings, and proven single/multi-hole platforms no longer require Hammer. Hammer is still the right tool for final visual dressing, freeform mesh sculpting, and visual inspection. The goal is not to pretend Hammer no longer exists; it is to reserve Hammer for the parts only Hammer can reliably judge.
